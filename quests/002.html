002 皮丘的旅途

一句话目标：把咕咕交给吉野市的小黄换取线索，再带着皮丘前往桐树林祠堂，让皮丘与森林中的同伴团聚。

接取地点

  • 吉野市（地图 3:67）：NPC 小黄（大木博士的助手），对象 localId 7，坐标约 (13,13)。[地图]

准备条件

  • 队伍中携带 咕咕（内部槽 163）。第一次与小黄对话只会请你把咕咕带来（置 flag 5699），不会接取任务。
  • 首次对话后她只说“目前沟通宝可梦还需要做一些准备……请你把咕咕带回来给我看看吧”。
  • 后续祠堂阶段队伍中需要有 皮丘（172）或皮卡丘（25），否则祠堂无反应。

操作步骤

  1. 在吉野市与小黄对话了解情况（她自称“我叫小黄，是大木博士的助手”）。
  2. 队伍中带着咕咕再次与她对话，回答“是”，在宝可梦选择界面把 咕咕（163） 交给她。 - 提交的若不是咕咕，她会说“不对不对，这只宝可梦怎么看也不像咕咕吧？”。 - 在提示“要将队伍里的皮丘放出来吗？”之类的选择前，本步骤会进入专门的选择流程（special 159），取消则她说“好吧……我期待着你的好消息！”。
  3. 交出咕咕后，她展示咕咕并给出线索：“……皮丘告诉我，跟它一起玩耍的另一只皮丘，看见了空地上有一阵扭曲便跑过去了看了一下，然后就消失不见了……我听说过一个叫桐树林的地方，那里时常会有超自然现象发生……那么你先带着皮丘去桐树林看看吧。”随后显示 接受任务:<皮丘的旅途> 与“带着皮丘去桐树林看看吧。”（置接取旗标 5794）。
  4. 前往 桐树林（地图 1:121），到祠堂前调查（坐标约 x6–7, y47；存在人物 localId 33 与调查点两个入口）。[地图]
  5. 先读祠堂说明：“桐树林里的祠堂……供奉着森林之神。”
  6. 选择“要将队伍里的皮丘放出来吗？”回答“是”。此时脚本用 special2(24) 做物种检查：队伍中须有 皮丘（172）或皮卡丘（25），否则只显示“似乎没有反应……”。
  7. 触发祠堂前剧情：皮丘与森林里的皮丘伙伴相聚，一位老者出现，念白包括“哎呀哎呀，不可以在祠堂恶作剧！森林之神会惩罚你们的！……据说是能够自由穿梭时间的宝可梦的力量造成的…”“……这不是连我也不知道是何时住进了这个森林的皮丘吗？……”以及赠送精灵球。
  8. 显示“刺刺耳皮丘钻进了[玩家/变量]的精灵球！”，获得 刺刺耳皮丘（内部槽 1100，等级 5）。

交付检查

  • 获得刺刺耳皮丘（species 1100，Lv5）。
  • 祠堂场景若队伍无皮丘/皮卡丘，只能看到“似乎没有反应……”，不会推进。

奖励

  • 刺刺耳皮丘（内部槽 1100，Lv5，直赠）。
  • 6 BracerPoints（addvar 0x5135, 6，完成分支）。
  • 无金钱、无道具。

容易卡住的位置

  • 必须先把 咕咕 带在身上才能推进；只对话一次不会接取。
  • 交给小黄的必须是咕咕，交错只会得到否定对白。
  • 祠堂阶段必须有皮丘（172）或皮卡丘（25），否则触发不了后续剧情。
  • 祠堂有两个入口（人物 localId 33 与调查点），都指向同一段旗标逻辑。

来源与待补字段

  • 来源包：data/quest_packets/002.json；相关脚本：0x08AAC1FE / 0x08AAC229 / 0x08AC2B8E / 0x08AC52D0 / 0x08AC5B42（吉野市），0x08D568C3 / 0x08AE646E / 0x08AE74A4 / 0x08AE74DA / 0x08F528BA / 0x08AE74FB / 0x08AE7EC7 / 0x08AE7545 / 0x08AE7E43 / 0x08AE8221 / 0x08AE7B77（桐树林祠堂）。
  • 待补字段：祠堂临时出现的隐藏对象（localId 51/52/53）名字未定位；“另一位皮丘伙伴”在数据中无名字；咕咕的获取来源不属于本包。
