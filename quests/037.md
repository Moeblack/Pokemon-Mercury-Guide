# 037 目标是虫系大师

一句话目标：帮桧皮镇一名向往成为虫系大师的女孩制作（凑齐）3 个速度球，供她捕捉飞天螳螂。

## 接取地点

- 桧皮镇（地图 [3:69](../../wiki_export/world/pages/maps/g03_n069.md)），女孩（local_id 12，坐标 30,16），位于碳工匠小屋（钢铁先生处）附近。
- 当前目录描述：帮助桧皮镇的女孩制作 3 个速度球；旧表描述作“目标是虫属性大师”，并注明“请来碳工匠小屋附近帮帮我”。

## 准备条件

- 前置旗标 4246 已置位（共用接取进度条件；置位剧情由 Main 定位；未置位时女孩只会说“你也是来找钢铁先生制作精灵球的吗？好多人都是这样。”）。
- 需能拿出 速度球（道具 243）×3；对白说明速度球要用白色圆柑果实制作。

## 操作步骤

1. 与女孩对话。满足前置后她说：桧皮镇馆主阿笔是虫属性宝可梦的专家、是她向往的目标；她想抓一只飞天螳螂，但总被它从球中逃脱；听说钢铁先生制作的速度球对飞天螳螂有 4 倍捕获几率，请你帮她做 3 个速度球（需要白色圆柑果实）。
2. 选择答应。脚本 `0x08AE6F7B` 置接取旗标 5847，显示“接受任务:<目标是虫属性大师>”，她说“那么就拜托你啦，谢谢你！”。
3. 凑齐 速度球 ×3（道具 243）。用白色圆柑果实制成 3 个即可。
4. 携带 3 个速度球回去找女孩。脚本以 `checkitem 243,3` 判定数量；足够时执行 `removeitem 243,3` 收下速度球，她说“就是这个速度球！太好啦，有了这个我一定能捕捉飞天螳螂……对了，这个送给你作为谢礼吧！”，并给出 白色香草（180）×1 与 经验糖果XS（536）×5。
5. 结算脚本 `0x08F523F7`/`0x08AE725C` 置完成旗标 5844、获得 3 点 BracerPoints 与 4000$。

## 交付检查

- 以背包内 速度球（道具 243）数量 ≥3 判定；交出后被移除 3 个。
- 数量不足时女孩只会问“你好，速度球的事怎么样了？”，不会结算。

## 奖励

- 白色香草（道具 180）×1
- 经验糖果XS（道具 536）×5
- 3 点 BracerPoints
- 4000$

## 容易卡住的位置

- 必须先满足前置旗标 4246，否则拿不到委托。
- 判定用的是背包里的 速度球（道具 243）实际数量，共需 3 个；速度球要自行用白色圆柑果实制作，不能凭空获得。
- 交付后再对话，她只会说“谢谢你，我现在就要去捕捉飞天螳螂试试！”。
