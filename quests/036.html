036 沉睡的潜能

一句话目标：帮助阿露福遗迹的超能力者集齐所有形态的未知图腾，向他展示“奇迹”，换取记录“觉醒力量”的招式学习器。

接取地点

  • 阿露福遗迹（目录关联地图 1:47），委托人为“阿露福遗迹的超能力者”。
  • 入口的确切子地图与 NPC 坐标未定位（本包无 event_roots，正文来自分支脚本，不能证明地图入口）；请勿据本页臆造坐标。

准备条件

  • 需能把所有形态的未知图腾收齐。脚本以 26 个形态旗标 5866–5891 全部置位为交付判定（与 035 的“26 种已确认文字”是同一组旗标）。

操作步骤

  1. 与超能力者对话。他描述徘徊在阿露福遗迹的未知图腾正释放某种不可思议的电波：“如果只是一只两只，那电波微弱得根本无法解读。但若是将所有形态的未知图腾聚集在一起……也许就能引发足以唤醒宇宙的共鸣。”
  2. 他提出委托：“如果你能将所有形态的未知图腾全都收服，并向我展示那个奇迹……我就将我从电波中领悟到的‘力量的真相’传授给你。”选择答应。
  3. 置接取旗标 3184，显示“接受任务:<沉睡的潜能>”，他说“去收集所有的未知图腾吧，我会在这里等你的好消息。”
  4. 收服所有形态的未知图腾，使形态旗标 5866–5891 全部置位。
  5. 再与他对话。脚本 0x09CD01FB 逐一检查 5866–5891：未集齐时只重复“去收集所有的未知图腾吧”；全部置位时转入结算 0x09CD02F4。
  6. 结算：他惊叹“这是何等惊人的共鸣！……这就是隐藏在每个生命最深处的潜能！……作为约定的回报，请收下这个吧。”赠予招式学习器（道具 298 TM10 觉醒力量）×1；随后显示“完成任务:<沉睡的潜能>”，获得 8 点 BracerPoints 与 9000$，置完成旗标 3185。
  7. 完成后他提供后续服务（脚本 0x09CD0344 起）：可查看某只宝可梦“觉醒力量”的属性；也可用 心之鳞片（道具 111）×1 为一只宝可梦改变觉醒力量的属性。

交付检查

  • 形态旗标 5866–5891 全部置位后与他对话即触发结算；完成旗标 3185 置位。

奖励

  • 招式学习器（道具 298 TM10 觉醒力量）×1
  • 8 点 BracerPoints
  • 9000$
  • 后续便利：查看 / 改变觉醒力量属性（改变需消耗心之鳞片×1）

容易卡住的位置

  • 入口 NPC 的确切位置未定位，本页不提供坐标；需在阿露福遗迹中找到超能力者本人。
  • 交付判定是 26 个形态旗标全部置位，缺一不可。
  • “改变觉醒力量属性”会消耗 1 个心之鳞片；“查看”则不需要。

技术证据（旗标 / 脚本 / 判定）
  • 接取/完成旗标：accept 3184（0x0C70）、complete 3185（0x0C71）。
  • 入口脚本 0x09CD0194（lockall + faceplayer）：先 checkflag 3185 → 完成态转 0x09CD0344（查看/改变潜能属性服务）；再 checkflag 3184 已接取 → 0x09CD01FB；否则走向委托对白与 yes/no。
  • 接取 0x09CD01DA：显示“接受任务:<沉睡的潜能>”，call 0x09CD0475（任务启动辅助），setflag 3184。
  • 进度判定 0x09CD01FB：连续 checkflag 5866…5891，任一为 0 → 0x09CD02EA（重复提示）；全置位 → 0x09CD02F4。
  • 结算 0x09CD02F4：setorcopyvar 32768,298 + 32769,1 + callstd 0（即赠道具 298 ×1）；对白说明为“觉醒力量”招式学习器；随后 addvar 20789,8、addmoney 9000、setflag 3185。
  • 后续服务 0x09CD0344：菜单“查看潜能属性 / 改变潜能属性”；查看用 special 159 选宝可梦后经 callasm 读觉醒属性；改变需 checkitem 111,1，成功后 removeitem 111,1。
  • 判定逻辑：comparevartovalue 32781,1 + goto_if 1 为“有/成功”分支；goto_if 0 为“任一形态旗标未置位”。
  • 备注：以上脚本来自 supplemental_branch_candidate，仅证明分支正文与旗标判定，不证明地图入口；故未给坐标。
