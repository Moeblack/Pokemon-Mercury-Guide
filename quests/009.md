# 009 冻土上的捉迷藏

一句话目标：在纯白冻土里找回跑散的宝可梦；找到两只后，南端的“木木枭”会引出 010 的索罗亚克事件。

## 接取地点

- 纯白冻土（地图 [52:23](../../wiki_export/world/pages/maps/g52_n023.md)）。到达该地图时由地图脚本自动触发，无需找人对话。
- 触发脚本 `0x09CD0EF4` → `0x09CD0EFE`：三只宝可梦从 (56,48)/(58,48)/(57,49) 附近跑开，显示“接受任务:<冻土上的捉迷藏>”与“三只宝可梦跑开了！\n必须尽快找到它们！”。

## 准备条件

- 需先完成『山顶的秘密』（完成旗标 3024），玩家会被传送到纯白冻土 52:23。
- 无需道具。

## 操作步骤

1. 进入纯白冻土 52:23 时自动演出：三只宝可梦跑开，接受任务（旗标 3025，变量 20943=4）。
2. 在纯白冻土 52:23 找到第一只：约 **(22,42)** 的宝可梦对象（脚本 `0x09CD0F8B`，local_id 4）。调查后设发现旗标 3034，并有一段确认对白。
3. 从 52:23 往南进入纯白冻土 [52:24](../../wiki_export/world/pages/maps/g52_n024.md)，找到第二只：约 **(30,27)** 的宝可梦对象（脚本 `0x09CD104C`，local_id 1）。调查后设发现旗标 3035。
4. 两只都找到后（脚本 `0x09CD10B3` 同时检查 3034、3035），纯白冻土 52:24 南端约 **(16,116)** 的对象会显现，那里就是 010 的“木木枭/索罗亚克”事件点。
5. 任务在 010 的战斗场景中一并完成（旗标 3026 在 `0x09CD11C2` 被设置）。

## 交付检查

- 需在 52:23 与 52:24 各找到一只隐藏宝可梦（3034、3035），随后触发 010。
- 完成旗标 3026 与『纯白的魅影』同时成立，没有单独的交付物品。

## 奖励

- 无明确奖励（该包内没有 additem/addmoney/addvar 记录）。

## 容易卡住的位置

- 纯白冻土 52:24 是 36×118 的大地图，目标在南端 y≈116，别只在新到区域转。
- 两只隐藏宝可梦有独立发现旗标（3034/3035）；第三只“木木枭”实为 010 的索罗亚克诱饵，不存在单独的第三只发现旗标。
- 相关对象的可见性由旗标 3043/3044/3045 控制，需通过上述两处触发才推进。
